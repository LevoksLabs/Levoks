# Home and project navigation

Mode: Operate. Extend the incumbent graphite, Inter, violet-selection and Lucide system.

Use a quiet navigation sidebar for all projects, starred projects, cloud projects, trash and user-created groups. Keep project search, sorting, grid/list choice and creation near the project collection. Project records carry their real name, modified date and document summary. Empty states explain the next action. Profile is a separate route sharing the home shell.

Local data remains device-scoped, including groups, stars and trash. Cloud saves remain explicit and account-scoped. Home must identify these boundaries. Opening a workplace URL loads only the requested project, including after reload; missing or trashed projects show recovery navigation rather than silently opening a different project.

Preserve the editor and its panels. Returning Home saves pending edits first. Existing project-switching controls also update the URL.
